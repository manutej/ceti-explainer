## Wave GL

Thirteen lanes landed on 2026-10-10 (37 in all): eight WebGL data-visualisation lanes (gl-instances, gl-heightfield, gl-ribbons, gl-pointcloud, gl-stack-city, gl-camera-rig, gl-post, gl-volume), the label solver gl-labels, and four flat perception lanes (uncertainty-hop, formula-bind, track-unit, scale-anchor, renderer p2d). The brief, the lane table and the rule for films (a move goes 3D only when one of the five GPU-earning rows of R-D §2 holds; otherwise it ships flat) are in [WAVE-GL.md](WAVE-GL.md). The research behind the lanes is in [frontier/](frontier/) (R-A GPU dataviz, R-B p5 GPU, R-C cinematic, R-D moves, PROBE-gl-backend); the evaluation seats are in SEATS-GL.md (landing: the file did not exist when this was integrated; arsenal/SEATS.md holds the earlier seats). The ms/frame column of these rows is the shoot.mjs figure; gl-post and gl-volume do not wait for the GPU there, so use the cost table in their cards (s/frame, 960x540 x2, SwiftShader).

## Core and tools

- arsenal/core/timeline.js: tracks, builder (play, wait, all, stagger, beat), scenes with local time, captions; MIGRATION.md shows how films drop seg()/T tables.
- arsenal/core/generator.js: generator-authored scenes compiled once to absolute intervals.
- arsenal/structures/structures.js: pure layouts (grid, wall, ring, columns, rows, timeline, tree, scatter) with transitions.
- arsenal/materials/drawn/materials.js: ink, pencil, stitch, chalk, marker, blueprint; arsenal/materials/shader: neon, halftone, riso, chalk filters.
- arsenal/brands/*.json (22 packs incl. ten derived from the CETI design system) + schema.json + tools/brand_check.py (WCAG contrast, vendored faces); tools/tweak.py derives hue/dark/light/contrast/accent/mono/type/tempo variants (22 twins in brands/derived); arsenal/patterns/palette renders every pack.

## What to use for what

| need | module |
|---|---|
| timing, scenes, captions without hand-tuned seg() tables | core/timeline.js (patterns/timeline), generator.js for authored sequences |
| lay out a count: grid, wall, ring, columns, rows, tree, scatter | structures/structures.js |
| draw a diagram, signature or network on | patterns/reveal |
| a number or word that turns into another | patterns/morph-type (patterns/particles-text for particles) |
| move the view across a map, timeline or grid | patterns/camera |
| point at something: callouts, bars, hand marks, spotlight | patterns/annotations |
| marks that carry data (rows, scatter, bars) | patterns/data-marks; thousands of marks: patterns/mass |
| cut between scenes | patterns/transitions |
| a look for the marks: ink, pencil, stitch, chalk, marker, blueprint | materials/drawn (shader looks are a post, not allowed at exec level) |
| a brand: pick one, derive one, check one | brands/ (22 packs), tools/tweak.py, tools/brand_check.py |

## Design-system bundle

arsenal/ds-bundle is the Claude Design design-system bundle (brand cards, lane cards, chromes, kit2 proof matrices,
tokens), built by `python3 arsenal/tools/ds_bundle.py`. The Claude Design project "CETI Explainer Arsenal" holds it;
regenerate the bundle after a pack or lane changes and sync it from a session with design access.

## Adopting a pattern in a film

1. Pick the axis values in film.json (brand, chrome, material); build with factory/kit2/build.py.
2. Time with arsenal/core/timeline.js instead of seg(); lay out counts with arsenal/structures; reveal with patterns/reveal; morph numbers with patterns/morph-type; move the camera with patterns/camera.
3. Run the gate; nothing in the laws changes (counts first, commit first, claims, honest line, brand card).
