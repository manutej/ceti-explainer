# p5-index · need to atlas page to arsenal module (p5.js 2.x, no web)

Documentation index for the drafting agent. Two hops: a visual or technical need leads to an atlas page, the page leads to an arsenal module or a p5 call.
Built 2026-10-10 from references/atlas (437 entities, 416 sources S1-S416, current to p5.js 2.3.4 of 2026-09-25), the arsenal cards and kit2. All paths are repo-relative.

## Contents
1. How to use this index (two hops, badges, S-ids, page types)
2. Need to pages table (typography, 2D, colour, WEBGL, images, math and seeds, timing, layout, physics, export, migration traps, performance)
3. Arsenal card to atlas backlinks (module id to documentation)
4. Live documentation when web access exists, and the authority rule
5. Known gaps (needs the atlas does not document)

## 1. How to use this index

1. **Hop 1, need to page.** Find your need in section 2. Open the atlas page (`references/atlas/pages/<slug>.md`); its Definition, Details and "In explainer work" give the 2.x behaviour, a pattern and its `[Sn]` citations.
2. **Hop 2, page to module or call.** The same row names the arsenal module id(s) that already implement it (ids as in `skills/atelier-draft/references/chain-recipes.md` section 1) and the p5 2.x call(s). Read the module card for knobs and pitfalls before wiring; do not re-implement.
3. **Module first?** Use section 3: module id to the pages its card cites. `arsenal/README.md` "What to use for what" is the shorter table of needs to modules.
4. **Cite when you write a card.** Every substantive line you add to a card.md or NOTES.md that rests on p5 behaviour gets the atlas page as `[[slug]]` and its S-id(s), copied from that page's `sources:` front matter or its Sources list (S-id text lives in `references/atlas/sources/SOURCES.md`). Never invent an S-id; a claim with no page is a gap (section 5), say so.
5. **Version badges** (inherited from the atlas): **[2.x]** exists only in 2.x; **[changed in 2.x]** the 1.x idiom you remember is wrong or renamed; **[1.x only]** removed; **[beta]** experimental; **[main / unreleased]** merged after 2.3.4, do not ship. LLM-remembered p5 is mostly 1.x: when a row says [changed in 2.x], trust the row, not memory.
6. **Conflicts are recorded, not resolved.** Where sources disagree (HDR vs P3, textToPoints signature, textWidth vs fontWidth, 2.3.0 date) see `references/atlas/pages/open-questions.md`; the row note says which side the factory uses.
7. **Page types** (graph `entities.jsonl`, 13 types): Module = a p5 reference module (`module-*`); Capability = a group of calls (`webgl-mode`); Construct = one call or class (`load-font`); Concept / Pattern / Technique = explainer ideas and recipes (`pure-function-of-t`, `arc-length-reveal`, `flow-field`); Tool / Library / Platform = outside software (`ffmpeg`, `ccapture`, `p5-woff2`); Release = version notes (`release-2-3`); Work / Practitioner = people and works; Site = provenance of a source host (`site-*`). For breadth, enter by hub: `references/atlas/pages/index.md` `references/atlas/pages/hub-language-core.md` `references/atlas/pages/hub-motion-rendering.md` `references/atlas/pages/hub-explainer-production.md` (people: `references/atlas/pages/hub-people-community.md`, source sites: `references/atlas/pages/hub-sites.md`).
8. **Synthesis pages** worth reading whole once: `references/atlas/pages/capability-map.md` `references/atlas/pages/explainer-engine-blueprint.md` `references/atlas/pages/video-export-pipeline.md` `references/atlas/pages/version-2x-migration.md` `references/atlas/pages/mastery-ladder.md` `references/atlas/pages/open-questions.md` `references/atlas/pages/frontier-2026.md`.
