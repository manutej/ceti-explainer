# ceti-explainer

**Course occupancy (E0).** When the brief is a short-course film (2-minute lecture, optional 5-minute seam test) rather than a deterministic SVG episode, occupy Tailor/Commit of noether-harness. ceti-research proposes the atlas. Command: `/sheaf-run course`. See COURSE-E0.md. Persist every generated asset immediately.

The **product skill**. `ceti-research` proposes. This skill tailors stills,
motion, narration, and a single-file HTML page until Φ holds, then commits.

## Quality bar (from CETI Lookbook, not its sentences)

- Unique signature visual per episode. Never a reused template.
- ABSOLUTELY STUNNING. Anything less is failure.
- Cream + vermillion + ink. No purple gradients, no emoji headings, no glassmorphism default.
- Mobile-ready, WCAG AA, `prefers-reduced-motion`.
- Anchored in real concepts. No fabricated facts.
- No text overlap with existing lookbook pages.

## Dual-loop occupancy

```
Propose   ceti-research     atlas of slots
Tailor    stills → motion → narration → HTML
          sheaf-glue on motif, claim, duration
Commit    2-minute film + HTML
Meta      5-minute expansion tests seams (new beats, same city)
```

Command: `/sheaf-run course`

## Episode contract

1. One metaphor family for the whole film (this course: maps of a city, vermillion thread).
2. 15-second shots, stitched. Prefer more short shots over one long take.
3. Narration in a calm editorial voice. No hype.
4. 2-minute cut is the product. 5-minute cut is the experiment that stresses glue.
5. HTML page has one signature motion that *is* the concept.

## When Φ fails

- Motif drift (bowls appear in a map episode without being operads) → `sheaf-repair` discrete alignment, not a new aesthetic.
- Claim without source → refuse commit.
- 5-minute expansion that contradicts the 2-minute lecture → abstain, do not override with polish.
