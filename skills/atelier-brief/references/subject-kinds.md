# Subject kinds · where the numbers come from, what the count is

| kind | the belief usually sounds like | fixture | where the claims come from | the count (one mark = ) | typical chain |
|---|---|---|---|---|---|
| concept (bias, paradox, law) | "X is obviously true" | one published study or dataset, named, dated | the paper's table; recompute every ratio from its counts | one person, trial, firm, project | structures + reveal (2D); webgl-scene + camera for a reversal that needs a second view |
| repository / codebase | "it's just scripts" or "it doesn't scale" | the repo at a commit, its branches and PRs | `python3 factory/tools/repo_topic.py <path> --id <id>`: files, LOC, tests, commits, PR numbers, measured timings; every number carries its command | one file, one test, one commit, one token | layers + data-marks + timeline; morph-type for a number that becomes another |
| product / feature | "customers want X" | one cohort, one release, one benchmark | telemetry export or a documented benchmark; cite the query or the doc | one user, session, request | fields or particles-text for flow; data-marks for the before/after |
| academy lesson | "the textbook rule" | the canonical worked example | the course notes; recompute | one unit of the example | grid-type + annotations; handwriting for the derivation |
| client case | "we did worse this quarter" | the client's own period, anonymised if asked | the client's numbers, with the sheet named in sources | one deal, lead, ticket | structures + palette switch (atelier-variant for their brand) |
| metric / KPI | "the number went down" | one period with a denominator | the dashboard's definition; the denominator is a claim | one event in the denominator | mass or physics for a settle; data-marks for the split |

Rules of thumb
- If the count would exceed ~5,000 marks, batch (one mark = k units) and make k a claim with a formula.
- A repository subject needs a reversal too: "small on the surface, deep underneath" shown by a second view
  (depth columns, a scale ladder), not told by a caption.
- A subject with no published or measured number is not ready; hand back the missing slot instead of inventing.
