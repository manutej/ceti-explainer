# Subject kinds · where the numbers come from, what the count is

| kind | the belief usually sounds like | fixture | where the claims come from | the count (one mark = ) | typical chain |
|---|---|---|---|---|---|
| concept (bias, paradox, law) | "X is obviously true" | one published study or dataset, named, dated | the paper's table; recompute every ratio from its counts | one person, trial, firm, project | structures + reveal (2D); track-unit (flat, evidence-first) for a reversal told as the same units re-partitioned; gl-stack-city when 3D earns it (WAVE-GL "Rule for films": place or parallax is the claim, marks beyond Canvas2D, or depth paces the reveal); webgl-scene + camera for a second view; uncertainty-hop for a paradox about a spread |
| repository / codebase | "it's just scripts" or "it doesn't scale" | the repo at a commit, its branches and PRs | `python3 factory/tools/repo_topic.py <path> --id <id> --rev <sha>`: history, tree, README, manifests, tests at one pinned commit, every number with a `recompute` command; folder and layer counts you add by hand carry their own find/grep command | one file, one test, one commit, one token | layers + data-marks + timeline; morph-type for a number that becomes another; scale-anchor for a ladder of scale |
| product / feature | "customers want X" | one cohort, one release, one benchmark | telemetry export or a documented benchmark; cite the query or the doc | one user, session, request | gl-ribbons for a funnel or queue (flow in depth, cost of delay; flat reveal paths if depth is not the claim); fields or particles-text for flow; data-marks for the before/after |
| academy lesson | "the textbook rule" | the canonical worked example | the course notes; recompute | one unit of the example | formula-bind for the derivation (terms fly into the marks that compute them); grid-type + annotations; handwriting for the derivation |
| client case | "we did worse this quarter" | the client's own period, anonymised if asked | the client's numbers, with the sheet named in sources | one deal, lead, ticket | structures + palette switch (atelier-variant for their brand) |
| metric / KPI | "the number went down" | one period with a denominator | the dashboard's definition; the denominator is a claim | one event in the denominator | uncertainty-hop for a spread before the commit; gl-volume for a distribution with a tail or cut; gl-instances (flat-100k) for the denominator at true scale; mass or physics for a settle; data-marks for the split |

Rules of thumb
- If the count would exceed ~3,000 marks, batch (one mark = k units) and make k a claim with a formula, or name `mass` in the chain (to ~50k) or gl-instances (10k-100k, WebGL) or scale-anchor (one unit to 10^5 as a zoom).
- A repository subject needs a reversal too: "small on the surface, deep underneath" shown by a second view
  (depth columns, a scale ladder), not told by a caption.
- A move goes 3D only when one of the five GPU-earning rows of arsenal/WAVE-GL.md "Rule for films" holds; otherwise take the flat lane (track-unit, uncertainty-hop, formula-bind, scale-anchor).
- A subject with no published or measured number is not ready; hand back the missing slot instead of inventing.
