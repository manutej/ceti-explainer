# Generative Design (p5 edition)

## Definition
Generative Design (Generative Gestaltung) is the book by Groß, Bohnacker, Laub and Lazzeroni whose p5.js code package is Apache-2.0 licensed [S390].

## Details
- The code package is organised into chapter folders 01_P (basic principles), 02_M (complex methods) and 03_A (applications) [S390].
- The Apache-2.0 licence allows reuse of its sketches in commercial explainer work with attribution [S390].

## In explainer work
- Its principles chapters (colour, shape, type) are a permissively licensed starting library for explainer visual systems (see [[kinetic-typography]]) [S390].
