## What it contributes
- lil-gui onChange fires per change; onFinishChange fires when a change completes, suited to slow handlers [S95]
- lil-gui has a UMD build exposing lil.GUI and default width 245 px adjustable via constructor or CSS vars [S95]
- lil-gui builds controllers from property type: add(obj, prop) yields checkbox/text/number/button; with min,max a slider; with array/object a dropdown [S95]
