# NYU ML-for-the-arts courses

## Definition
NYU's ML-for-the-arts courses — ITP's Machine Learning for the Web and IMA's Introduction to Machine Learning for the Arts — teach creative ML with ml5.js and p5.js [S215][S216].

## Details
- Machine Learning for the Web (Yining Shi) uses ml5.js, p5.js, TensorFlow.js, Teachable Machine and RunwayML and emphasises creative use over theory [S215].
- IMA's ML for the Arts uses p5.js, ml5.js, TensorFlow.js and Runway and needs no prior programming [S216].
- An ITP Camp 2023 session taught training in Teachable Machine, exporting, and running with ml5 in p5 [S217].
- ml5.js is maintained by NYU ITP/IMA and NYU Shanghai IMA, with early funding from a 2018 Google Research Award [S219].

## In explainer work
- The train-in-GUI, deploy-in-p5 pipeline lets an explainer show a live classifier reacting on canvas; check current ml5 docs, since 2.x constructors return promises (see [[ml5js]], [[teachable-machine]]) [S217][S277].
