# Revideo docs (source site)

## Definition
**Revideo docs** — the documentation of Revideo, a fork of Motion Canvas for programmatic video; operated by Revideo. [S230]

Kind: **docs**; 2 registered sources, 2 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S230][S311]

## What it contributes
- Revideo was forked from Motion Canvas and shares largely the same animation API [S230]
- Motion Canvas `loop` never finishes, so it must be run concurrently (via yield or spawn) [S311]
- Revideo's `sequence` starts tasks at a fixed delay apart without waiting for each to finish, while `chain` runs them strictly one after another [S311]
