# Introduction to Computational Media (ITP)

## Definition
Introduction to Computational Media (ICM) is NYU ITP's seven-week foundation course that uses p5.js as its primary platform and starts in the p5 web editor [S214].

## Details
- Weekly topics run drawing, animation/variables, interaction/conditionals, loops, functions, objects/arrays, then DOM [S214].
- Grading: assignments 40%, participation 50%, final presentation 10%, with student blogs [S214].
- In 2018 Processing Foundation teaching fellows revised NYC's Introduction to Computational Media course, adding teacher notes and a public p5.js curriculum site [S209].
- Shiffman teaches at NYU Tisch's ITP [S180].

## In explainer work
- ICM's topic order is a tested progression for teaching explainer primitives from static drawing to animated, interactive sketches (see [[mastery-ladder]]) [S214].
