# D3.js (source site)

## Definition
**D3.js** — a docs source at d3js.org, credited to Observable / D3; the wiki uses it for “D3 docs, What is D3?”. [S409]

Kind: **docs**; 1 registered source, 1 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S409]

## What it contributes
- D3's docs point to Observable Plot as the simpler option for common charts [S409]
- D3 describes itself as a low-level toolkit of about 30 modules with no concept of charts and no default presentation [S409]
- D3 targets web standards, mainly SVG and Canvas, and its data join (enter/update/exit) enables animated transitions between data states [S409]
