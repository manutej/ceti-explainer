## What it contributes

- Mediabunny: JS media toolkit that supersedes mp4-muxer; includes CanvasSource for canvas-to-video [S148]
- CanvasSource: class taking a canvas plus VideoEncodingConfig; add(timestamp, duration) encodes the current canvas state [S148]
