# openFrameworks

## Definition

openFrameworks is an MIT-licensed C++ creative-coding toolkit for Windows, macOS, Linux, iOS and Android with 1,500+ community addons, wrapping OpenGL, OpenCV and FreeType. [S411]

## Details

- It targets creatives who want low-level access to media data. [S411]
- Etienne Jacob uses it alongside Processing for loop animations. [S185]
- No sourced head-to-head with p5 for explainers exists; scope descriptions come from vendor pages only. [S411]

## In explainer work

For explainer video it sits in the offline, native-rendering camp: strong when performance or heavy media matter, but it lacks p5's browser distribution and instant sharing (inference from scope descriptions). [S411][S412]
