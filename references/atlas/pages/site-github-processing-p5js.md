# GitHub: processing/p5.js (source site)

## Definition
**GitHub: processing/p5.js** — the main p5.js repository: releases, issues, pull requests, wiki and the source tree at several tags; operated by Processing Foundation. [S4]

Kind: **primary**; 31 registered sources, 30 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S4][S10][S20]

## What it contributes
- 2.3.4 (25 Sep) is marked Latest on the releases page; 2.4 work continues on main [S10][S122]
- noiseSeed documentation does not mention randomSeed and the two are separate seeding paths (noise uses its own table; random uses `_lcg_random_state`) [S76][S77]
- 2.0 adds `worldToScreen`/`screenToWorld` [S4]
- With withinBounds true, map clamps via constrain [S79]
- Issue #6311 had no recorded resolution in the fetched thread. [S251]
- p5.js 1.x was frozen (no further updates) at end of March 2026 [S114]
- Tree-shaking is considered a major effort outside current scope [S295]
- p5.Vector constructor empties values if any argument is non-finite [S78]

- Coverage: 31 sources (30 rated primary, 1 secondary by the researchers); year range 2025–2026, 25 without a recorded date. [S4][S10][S20]

- Researcher caveat on S265: concerns 2.1.1. This limits how far the wiki leans on the page [S265]
- Researcher caveat on S361: 1.11.x line. This limits how far the wiki leans on the page [S361]
- Noted gap: The reference pages do not mark which color modes are 2.x-only; the release notes  list them as new, and the page lists RGBP3 which the release notes do not mention. Treat RGBP3 timing as unverified. [S4]
- Noted gap: Issue 4992 is old and its maintainer comments predate 2.0; they are not current state. PR 8088 status (merged or not) is unverified, so fontWidth() availability in 2.x is uncertain. [S43]
- Noted gap: Shiffman's quote "technically a value noise" is paraphrased; that p5 noise is not true gradient Perlin is supported by both NoC and the source comment, with no source disagreeing. [S76]
