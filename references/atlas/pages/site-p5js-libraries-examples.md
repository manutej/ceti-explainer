# p5.js Libraries and Examples (source site)

## Definition
**p5.js Libraries and Examples** — the p5js.org community-libraries directory and the official example gallery pages; operated by Processing Foundation / p5.js. [S156]

Kind: **docs**; 3 registered sources, 3 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S156][S299][S300]

## What it contributes
- The libraries page lists 54 libraries in 19 categories. [S156]
- The p5 library directory marks no Animation or Export library as compatible with p5 v2 [S300]
- The page lists p5.Riso as "generates files for Risograph printing" by Sam Lavigne and Tega Brain. [S156]
