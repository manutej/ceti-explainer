# GitHub: mattdesl/canvas-sketch (source site)

## Definition
**GitHub: mattdesl/canvas-sketch** — the canvas-sketch framework docs for animated sketches and exporting artwork; operated by Matt DesLauriers. [S139]

Kind: **primary**; 6 registered sources, 6 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S139][S140][S399]

## What it contributes
- canvas-sketch ships an official p5.js example named animated-p5.js, linked from its WebGL docs page [S400][S401]
- canvas-sketch endless animations with no duration export frames forever [S140]
- canvas-sketch's docs say it can be combined with ThreeJS, P5.js, Pixi, Regl, D3 and similar libraries [S399]
