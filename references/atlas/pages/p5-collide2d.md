# p5.collide2D

## Definition

p5.collide2D (Ben Moren) provides 2D boolean collision-detection functions with Vector variants such as collidePointPoly and collideCircleCircle. [S162]

## Details

- Maintenance 2026: npm 0.7.3 published 2020-07-13 (registry modified 2022-05-12); about 589 stars; licence CC-BY-NC-SA-4.0, derived from a CC BY-NC-SA book, so non-commercial. [S159][S162]
- It is geometry tests only, versus Matter.js for full dynamics. [S162][S171]
- p5 2.x compatibility: undocumented, though pure maths plausibly still works (inference). [S162]
