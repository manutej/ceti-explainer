# Tweakpane docs (source site)

## Definition
**Tweakpane docs** — the documentation of a compact JavaScript GUI-parameter pane; operated by cocopon. [S94]

Kind: **docs**; 2 registered sources, 2 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S94][S110]

## What it contributes
- Tweakpane has migration guides to v4 and from dat.GUI [S94]
- Tweakpane can load from jsDelivr as an ES module (`import {Pane}` from tweakpane@4.0.5 dist) in a script type=module tag [S110]
- Tweakpane supports Number, String, Boolean, Color, Point bindings and monitor bindings including graph, plus folders, buttons, tabs, blades, theming, plugins [S94]
