# ml5.js (source site)

## Definition
**ml5.js** — the website and docs of ml5.js, the friendly machine-learning library for p5.js; operated by ml5.js project. [S173]

Kind: **primary**; 3 registered sources, 3 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S173][S219][S277]

## What it contributes
- ml5.js mission: make ML approachable for artists, creative coders and students; emphasizes ethics and bias [S219]
- In p5 2.x, ml5 constructors return promises (`await ml5.faceMesh()`), but `ml5.neuralNetwork` stays synchronous [S277]
- ml5.js is maintained by NYU ITP/IMA and NYU Shanghai IMA, with early funding from a 2018 Google Research Award [S219]
