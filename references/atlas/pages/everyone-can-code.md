# Everyone Can Code

## Definition
Everyone Can Code is Niklas Peters's free ten-module p5.js curriculum for students with low computer literacy, published via the Processing Foundation in 2017 [S210].

## Details
- Modules run about 90 minutes; early ones teach basic computer skills before the p5 web editor [S210].
- Peters reported students were excited when their first shapes responded to code changes [S210].
- The curriculum is free on GitHub [S210].

## In explainer work
- Its half-instruction, half-experimentation module shape is a template for workshop-style explainer sessions [S210].
