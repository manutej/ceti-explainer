# Craig S. Kaplan

## Definition
Craig S. Kaplan (isohedral) is an academic who did Genuary 2024 in p5.js, sharing sketches through the web editor as a catalogue for a creative-coding course that had used Processing [S388].

## Details
- His Genuary 2024 run was written in p5.js and shared via the p5 web editor [S388].
- He used Dave Pagurek's Contact Shadow p5 filter, deliberately underpowered, to get a pencil-like rendering [S388].
- He reports that daily prompts create real time pressure, leading to barebones entries and an abandoned run after day 26 [S388].
- Spatial hashing — computing parts of an infinite scene independently from coordinates — appears in his catalogue [S388].

## In explainer work
- Spatial (coordinate) hashing makes any tile of a scene reproducible without global state — useful for scrubbable explainers that must render frame N cold (see [[seeded-determinism]]) [S388].
- His Genuary post is one of few documented p5-in-the-classroom catalogues [S388].
