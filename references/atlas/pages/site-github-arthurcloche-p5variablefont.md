## What it contributes
- The p5.variableFont library targets p5.js 1.7.0 and needs opentype.js 1.3.4 [S45]
- p5.variableFont warns that unavailable or misnamed variations fall back to the default font [S45]
- p5.variableFont does not support WEBGL, and its textToPoints cannot animate variable axes because opentype.js cannot set axis values [S45]
