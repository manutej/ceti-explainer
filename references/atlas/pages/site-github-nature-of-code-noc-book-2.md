# GitHub: nature-of-code/noc-book-2 (source site)

## Definition
**GitHub: nature-of-code/noc-book-2** — the source repository of the second edition of The Nature of Code; operated by Daniel Shiffman. [S383]

Kind: **primary**; 1 registered source, 1 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S383]

## What it contributes
- NOC exercise sketches standardise on createCanvas(640, 240) and are re-saved under a Nature of Code web-editor account. [S383]
- The 2024 NOC source lives in a private Notion database, exported as HTML by a GitHub action, then built to PDF with Magicbook and to the web with Gatsby. [S383]
- p5.js Web Editor: Browser IDE that Coding Train and NOC sketches are hosted in [S383]
- Magicbook: Book build tool used to produce the NOC print PDF [S383]
