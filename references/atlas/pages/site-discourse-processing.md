# Processing Community Discourse (source site)

## Definition
**Processing Community Discourse** — the official forum where p5.js users, contributors and maintainers post questions, dev updates and workarounds; operated by Processing Foundation community. [S75]

Kind: **community**; 24 registered sources, 2 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S75][S100][S113]

## What it contributes
- 2.x adds new color modes including OKLCH via colorMode [S75]
- The same poster says saveFrames is limited to 15 seconds [S131]
- CCapture's GIF output needs a separate gif.worker.js file [S236]
- The thread did not answer how p5.Color is stored in Local Storage under 2.x [S124]
- A 2018 Processing Discourse reply states Khan uses a customized Processing.js [S203]
- A community workaround is plain VS Code with a jsDelivr script tag pinned to 2.2.2 [S238]
