# Hub: Source sites

## Definition
This hub indexes every web site (or repository host) that supplies evidence to the atlas: 136 site pages covering all 416 registered sources, S1 to S416. [S1][S10]

Each site page records what the site is, what the wiki drew from it, which entity pages cite it, and how far to trust it. The p5.js documentation family dominates the evidence base, which is why the p5js.org domain is split into several pages. [S1][S342][S75]

## Details
### Grouping decisions
- One page per registrable domain by default; hosts with several unrelated parts are split into separate site pages, for example p5js.org into reference, tutorials, libraries and examples, and about/contribute pages. [S1][S342]
- The beta.p5js.org preview and the frozen v1.p5js.org archive share one page, because both mirror p5.js documentation under a different version label. [S10][S75]
- Every GitHub repository is its own site, and raw.githubusercontent.com files are folded into the repository they come from; each YouTube channel is its own site. [S10]
- Mirrors of one third-party agent skill on several hosts are grouped into one page, and NYU, jsDelivr, npm, arXiv, Art Blocks, ml5.js and Hacker News hosts are each merged across their sub-domains. [S75]
- Single-source blogs and press sites keep their own short pages, because the total stayed under the 160-page ceiling set for this cluster. [S1]
