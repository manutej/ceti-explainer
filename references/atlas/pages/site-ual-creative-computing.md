# UAL Creative Computing Institute wiki (source site)

## Definition
**UAL Creative Computing Institute wiki** — a university wiki with a how-to on exporting p5.js as video; operated by University of the Arts London. [S132]

Kind: **community**; 2 registered sources, 0 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S132][S154]

## What it contributes
- The UAL p5 video-export guide uses CCapture and warns that editor auto-refresh can crash a capture. [S132]
- UAL's guide uses a capture library inside the p5 web editor: start capture when frameCount == 1, save at end of draw(), with captureLength set from fps [S154]
- A UAL wiki tutorial captures via CCapture with webm format at 60 fps by starting at frameCount 1 and saving at a capture length [S132]
