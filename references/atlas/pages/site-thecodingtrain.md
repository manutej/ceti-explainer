# The Coding Train website (source site)

## Definition
**The Coding Train website** — the video-tutorial and coding-challenge catalog run by Daniel Shiffman, with p5.js tracks and challenge pages; operated by Daniel Shiffman. [S46]

Kind: **community**; 13 registered sources, 8 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S46][S87][S88]

## What it contributes
- Coding Challenge pages embed the video, list timestamped chapters, link a runnable p5 web-editor sketch, and host a community "showcase" of remixes. [S142][S386]
- Challenge 130 teaches DFT, epicycles, Euler's formula, complex numbers [S221]
- Shiffman teaches at NYU Tisch's ITP and is on the Processing Foundation board [S180]
- Coding Train I.2 contrasts random() with noise(), explains cosine interpolation and octaves [S87]
- A Coding Train lesson says one letter can have multiple contours, each with an angle property [S46]
