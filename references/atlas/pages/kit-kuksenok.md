# Kit Kuksenok

## Definition
Kit Kuksenok has been p5.js Project Lead since 2024 and is listed as a Processing Foundation Engineering Manager; they steered the 1.x→2.x transition in public [S342][S50][S75].

## Details
- Kuksenok ran the "p5.js 2.0: You Are Here" dev-updates thread (April 2025 to June 2026) that tracked the 1.x freeze and the Editor default switch [S75].
- They co-authored the official 2.0 typography tutorial with Dave Pagurek, covering animation, interaction and type in 2D and 3D [S116].
- On Discourse they answered migration questions by pointing users to the [[p5js-compatibility]] README with side-by-side 1.x/2.x code and a Promise.all loading example [S124].
- They hosted the p5.strands talk at Libre Graphics Meeting on 22 April 2026, given with Pagurek, Plowden, Singh and Lim [S296][S50].

## In explainer work
- Their migration guidance is the practical route for explainer code written against 1.x idioms: async loading, new curve API, compatibility add-ons as a bridge **[changed in 2.x]** [S124].
- The typography tutorial they co-wrote is the primary doc for 2.x [[kinetic-typography]] [S116].
