# Isohedral (source site)

## Definition
**Isohedral** — a primary source at isohedral.ca, credited to Craig S. Kaplan; the wiki uses it for “Genuary 2024”. [S388]

Kind: **primary**; 1 registered source, 1 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S388]

## What it contributes
- Kaplan used Dave Pagurek's Contact Shadow p5 filter, deliberately underpowered, to produce a pencil-like rendering. [S388]
- Kaplan says daily prompts create real time pressure, leading to barebones entries and an abandoned run after day 26. [S388]
- Craig Kaplan wrote Genuary 2024 sketches in p5.js, shared through the p5 web editor, as a catalogue for a creative-coding course that had previously used Processing. [S388]
