# OSS Microgrants Program

## Definition
The OSS Microgrants Program is a Processing Foundation scheme funding individual open-source contributors for scoped p5.js work [S294][S275].

## Details
- 2026 microgrants funded p5.strands instancing by Akshat Patil and translation of GLSL examples into p5.strands by Dorine Tipo [S275][S294].
- The instancing work produced the `instances()` API merged for p5.js 2.4 **[main / unreleased]** [S275].

## In explainer work
- Both 2026 grants target the GPU path that matters most for mass-element explainer scenes: instancing and readable strands examples (see [[gpu-instancing]], [[p5-strands]]) [S275][S294].
