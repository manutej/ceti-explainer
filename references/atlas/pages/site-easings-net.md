# easings.net (source site)

## Definition
**easings.net** — a docs source at easings.net, credited to Andrey Sitnik / Ai (easings.net); the wiki uses it for “Easing functions cheat sheet”. [S80]

Kind: **docs**; 1 registered source, 1 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S80]

## What it contributes
- easings.net lists Sine, Quad, Cubic, Quart, Quint, Expo, Circ, Back, Elastic, Bounce, each with In/Out/InOut [S80]
- Easing function: Function mapping progress 0..1 to eased progress, applied before lerp [S80]
- Easing families: Ten families each with In, Out, InOut variants [S80]
- easings.net: Reference site for standard easing curves and formulas [S80]
