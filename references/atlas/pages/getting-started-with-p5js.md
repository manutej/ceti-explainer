# Getting Started with p5.js

## Definition
Getting Started with p5.js is the Make: beginner book by Lauren Lee McCarthy, Casey Reas and Ben Fry (2015 per bibliographic listings) [S353].

## Details
- It is co-authored by p5.js's creator and Processing's two co-founders [S353][S344].
- Its 2015 date means its loading examples predate the 2.x removal of `preload()` **[1.x only]** idioms (inference from date and [S11]).

## In explainer work
- Useful for the sketch mental model, but its code needs 2.x translation — async setup, new curve API — before use in modern explainers (see [[version-2x-migration]]) [S11].
