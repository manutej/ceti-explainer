# Coding Challenges

## Definition
Coding Challenges are one-off Coding Train project videos that build a sketch on camera and ship web-editor code, chapters and a remix showcase; most use JavaScript with p5.js [S182][S386].

## Details
- The catalog's first page lists #144 to #188, newest dated April 2026 [S182].
- Most use p5.js; some use Processing, ml5.js, d3.js, Node.js, toxiclibs.js, Runway or AppleSoft BASIC [S182].
- Examples: Wolfram CA (#179), Apollonian Gasket (#182), Wave Function Collapse (#186), Voice Chatbot (#188) [S182].
- Each page embeds the video, lists timestamped chapters, links a runnable p5 web-editor sketch and hosts a community showcase [S386][S142].
- #86 recreates a Bees and Bombs cube wave with oscillation, WEBGL and position offsets; #135 teaches GIF loops with paper sketching, easing, `saveFrame()` and a record flag [S142][S387].
- #81 teaches circle morphing by sampling both shapes to matching points and lerping [S341].
