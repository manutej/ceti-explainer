# GitHub: JazonJiao/Manim.js (source site)

## Definition
**GitHub: JazonJiao/Manim.js** — a JavaScript port of Manim; operated by Jazon Jiao. [S328]

Kind: **primary**; 1 registered source, 1 rated primary. It is one of the source sites indexed in [[hub-sites]]. [S328]

## What it contributes
- Manim.js's `setup2D` helper fixes 30 fps on a 1200×675 canvas [S328]
- Manim.js schedules objects with a `start` parameter given in frames, and each class's `show()` is called from `draw()` [S328]
- Manim.js replicates 3Blue1Brown's engine on p5.js, focuses on linear algebra and graph algorithms, and holds its author's YouTube animation sources. [S328]
