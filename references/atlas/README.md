# p5.js Explainer Atlas (reference index)

A cited wiki on building explainer animations with p5.js 2.x, generated by Manu on 2026-10-08 with the
noether-wiki tooling: 300 pages plus 136 source-site pages, 416 sources, 2,561 typed triples, five hubs.
It is the plugin's reference index: every technique, library and capability the factory may use should
resolve to a page here, and every pattern the arsenal ships should cite the page it rests on.

- `pages/index.md` is the home; hubs: hub-language-core, hub-motion-rendering, hub-explainer-production,
  hub-people-community, hub-sites. Synthesis pages: capability-map, explainer-engine-blueprint,
  video-export-pipeline, version-2x-migration, frontier-2026, mastery-ladder, open-questions.
- `graph/entities.jsonl` (437 entities, 13 types) and `graph/triples.jsonl` are the backlink graph.
- `_meta/` holds the ledger, escapes, conflicts and baseline of the wiki build; `sources/SOURCES.md` S1–S416.
- `atlas.html` is the standalone reader (index rail, backlinks, search). It loads marked and p5 from CDNs.

Conventions the plugin inherits from it: version badges [2.x] / [changed in 2.x] / [main / unreleased];
every substantive line cites an S-id; conflicts are recorded, never silently resolved.
