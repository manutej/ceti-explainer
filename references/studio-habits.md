# Studio habits — the house defaults this studio drifts toward (read before any series; series.py checks them)

A habit is not a sin; it is a default that stopped being a decision. When a piece uses one, the concept must say
why (the brief needs it), or choose differently. Rows are machine-read by `scripts/series.py`:
`| id | name | ground L C h | accent hue or - |` (OKLCH; L 0–1, C 0–0.4, h degrees).

| id | habit | ground | accent | first seen | evidence |
|---|---|---|---|---|---|
| H1 | cream paper + hairline ink + one vermilion "the one" accent | ground 0.95 0.02 85 | accent 32 | gallery v1, 2026-10-05 | 6/8 cream, 4/8 vermilion; named independently by cliché, colour, composition, intent seats |
| H3 | CETI-dark #0E1014 as the only dark | ground 0.17 0.01 264 | accent - | gallery v1 | bathysphere + torn-archive identical ground |

Non-machine habits (judged by seats; listed so concepts avoid them on purpose):
- H2 the seed changes one thing; the layout is fixed (6/8 in gallery v1). Give the layout a flex dimension.
- H4 horizontal-line siblings: stacked horizontal rules as the default structure (3/8).
- H5 fixed-pixel constants that break `?w=` scaling (6/8, craft seat).
- H6 a framed object floating on a large empty page with a hard left margin ("editorial plate" layout, 5/8).
