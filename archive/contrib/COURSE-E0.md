# Course occupancy — Experiment E0

The animated SVG episode (SKILL.md, LONGFORM.md) is the default product.
This file is the **film / short-course occupancy** used when the brief is a
2-minute lecture that may expand to a 5-minute seam test.

Command: `/sheaf-run course`

Tagline: Glue what the dual-loop conserves.

## Dual-loop occupancy

```
Propose   ceti-research     atlas of slots
          sheaf-kernel + localize ∥ preserve
Tailor    stills → motion → narration → HTML
          sheaf-glue on motif, claim, duration
Commit    2-minute film + lookbook HTML     only if Φ
Meta      5-minute expansion, same city     zero weight
```

## Quality bar (lookbook as bar, not corpus)

- Unique signature visual per episode. Never a reused template.
- Cream `#FAF7F2` · vermillion `#D94F30` · ink `#2C2A28`.
- No purple gradients, no emoji headings, no glassmorphism default.
- Mobile-ready, WCAG AA, `prefers-reduced-motion`.
- Anchored in real concepts. No fabricated facts.
- No text overlap with `ceti-lookbook` pages.

## Episode contract

1. One metaphor family for the whole film.
2. 15-second shots, stitched. Prefer more short shots over one long take.
3. Narration in a calm editorial voice. No hype.
4. 2-minute cut is the product. 5-minute cut is the experiment that stresses glue.
5. HTML page has one signature motion that *is* the concept.

## Localization repair (E0)

Generator stores drop stills, clips, and voice files. **Persist every asset
to the episode folder immediately** after it is created. A later path is not
a path.

## When Φ fails

- Motif drift → `sheaf-repair` discrete alignment, not a new aesthetic.
- Claim without source → refuse commit.
- 5-minute expansion that contradicts the 2-minute lecture → abstain.
- Single-file mux that has no valid container → abstain. Keep the conserved
  stills. Do not polish a broken stitch into a lecture.
